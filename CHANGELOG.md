# expo-app-info

## 0.1.0

Initial release.

- List every Expo (EAS) app in your account, with its latest build version per platform, from any directory.
- Zero runtime dependencies, `EXPO_TOKEN`-only authentication.

See the [v0.1.0 GitHub Release](https://github.com/eas-flow/expo-app-info/releases/tag/v0.1.0) for the full notes.

> From here on, entries in this file are generated by [Changesets](https://github.com/changesets/changesets) (`npx changeset` when opening a PR, `npx changeset version` to apply).
