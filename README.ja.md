# shelfit

[English](./README.md) | 日本語

shelfit ファミリーのCLIツール群のモノレポです。いずれも非公式・依存関係ゼロの小さなツールで、あるプラットフォーム上で作り上げたものを、どのディレクトリからでも一覧表示します。

各ツールは `packages/*` 配下の独立したnpmパッケージとして、それぞれ個別にバージョン管理・公開されます。

| パッケージ                                            | 機能                                                                                                   |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [`@my-shelfio/expo-shelfit`](./packages/expo-shelfit) | アカウント内のすべての Expo (EAS) アプリを、プラットフォームごとの最新ビルドバージョンとともに一覧表示 |

今後、GitHub・Qiita向けなどのツールが `packages/` 配下に追加される可能性があります。

インストール・使い方は各パッケージ自身のREADMEを、開発環境のセットアップ・チェック・リリースプロセスは [CONTRIBUTING.md](./packages/expo-shelfit/CONTRIBUTING.md) を参照してください（本リポジトリは npm workspaces によるパッケージ独立バージョニング・公開を採用しています）。
